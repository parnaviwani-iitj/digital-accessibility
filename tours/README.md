# Tours section

The AccessTravel demo is integrated at `/tours/` using the portal's shared login and accessibility preferences. It includes destination search, estimated costs and budget filtering, traveller names, optional voice search, accessibility requests, booking estimates and a printable invoice.

All destinations, hotels, prices and bookings are fictional examples. Booking details remain in the browser page and are not submitted to the server or saved. The invoice is an estimate, not a confirmed booking.
